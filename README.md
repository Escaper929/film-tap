# film-tap

碰一下贴在机身上的 NFC 挂件，就知道这台相机里装的什么胶卷、装了多久、还剩几张。

## 它解决什么

胶片一卷能拍很久，几台机身轮着用的时候，很容易忘记某台机器里装的是什么卷、
什么时候装的、还剩几张没拍完。

这个 App 把「机身 ↔ 当前胶卷」的状态记在手机上，靠一个挂在背带上的 NFC 挂件直达：

- 挂件里写一条 URL 记录：`https://<你的域名>/?c=<机身ID>`
- 手机碰一下 → 直接打开那台机身 → 看到当前卷、装了多少天、还剩几张
- 换卷只改 App 里的数据，**标签一辈子只写一次**

## 功能

- **机身管理** —— 名称、品牌、型号、画幅（135 / 120 / 110 / 大画幅）
- **机内胶卷** —— 装卷、过片计数与张数进度条、回卷自动归档
- **推拉提示** —— 填了实拍 EI 自动算推拉档位，送冲扫时提醒你交代店家
- **装卷天数** —— 超过 180 天标「该冲了」，超过 365 天亮红
- **拍摄历史** —— 每台机身拍过的卷、各用了多少天
- **统计** —— 机身数、累计快门、常用胶卷 Top 5
- **冲扫备注** —— 一键复制成能直接发给冲扫店的说明
- **备份** —— JSON 导出导入；可选同步到自己的 NAS（WebDAV）

## 数据与隐私

**所有数据默认只存在你这台设备的浏览器里**，没有服务器、没有账号。
存储键是 `filmtap.v1`。

> 项目原先叫 `film-nfc`，改名时存储键一并从 `filmnfc.v1` 换了过来。
> 代码里保留了**读取时自动接过来**的逻辑，所以改名前记的机身不会丢 ——
> 打开新版本时会自动把老键的数据搬到新键，之后一切以新键为准。

NAS 同步是可选的，需要你自己填 WebDAV 地址与账号。凭据只保存在本机
`localStorage`（键 `filmtap.webdav`），**不会写进代码，也不会随网页发布出去**。

> ⚠️ 千万别把 NAS 地址或密码硬编码进源码。仓库是公开的，一旦提交，
> 密码就永久留在 Git 历史里 —— 删掉代码也没用，必须改密码 + 重写历史才能挽回。

## 怎么用

线上地址（GitHub Pages，发布自 `main` 分支根目录，推一次自动更新）：

**https://escaper929.github.io/film-tap/**

NFC 标签里写的就是这个地址加上机身 ID：

```
https://escaper929.github.io/film-tap/?c=<机身ID>
```

`#/settings` 页的「已登记的机身 ID」会列出每台机身对应的完整 URL，直接复制即可。

本地预览：

```bash
python -m http.server 8080
```

> 直接双击 `index.html` 只能看界面 —— `file://` 下 Service Worker 不注册、离线缓存失效，
> 而且标签网址会算成 `file:///C:/...`，写进标签毫无意义。

打开后点「载入示例数据」可以先看看成品长什么样。

## 一次性的准备（每台机身做一次）

1. **登记机身** —— 起个短的机身 ID（`m6` / `fm2` / `xa2`），填名称、品牌、型号、画幅
2. **写标签** —— 用 NFC Tools 写入一条 **URL** 记录，内容就是上面那串地址。
   必须是 URI 记录且放**第一条**：iOS 后台读取只认 URI 记录，多条时只用第一条，
   也不支持自定义 scheme（`film://` 这种写了也读不到）
3. **打印挂件** —— `python model/build_fob.py` 出 `fob.stl`，层高 0.16mm，
   打完**第 17 层**（Z = 2.72mm）暂停放入标签，再封顶 2.24mm

标签只写这一次，之后换卷全在 App 里改。

## 自检与截图

```bash
node _selftest.js      # 全部视图渲染 + 过片 / 装卷 / 改名迁移 / 凭据护栏
python _shots.py       # 需先起本地服务，截图输出到 shots/
```

`_selftest.js` 里有一道**凭据护栏**：只要 `index.html` 出现内网地址，
或 `WEBDAV_AUTH = '...'` 这类硬编码，自检直接失败。

## 硬件

挂件是 3D 打印的，中间留了 NTAG213 / 215 / 216 圆片标签的腔体：
打到指定层高暂停 → 放入标签 → 继续封顶。

两个硬约束：**别用磁铁固定**（金属会让 NFC 直接失效）、
**别平贴金属机身**（天线失谐）。走穿绳孔挂在背带上。

## 历史

上一代是 `film-camera-tracker`（胶片管家）：纯手动索引、没有 NFC 概念。
这一版把它的过片计数、统计页、机身结构化字段、NAS 同步吸收进来，
换成 NFC 直达的架构重做。

项目名统一成 `film-tap` 之前叫过 `film-nfc`，界面标题叫过「胶片簿」——
仓库名、目录名、界面名已经全部统一，不再是三个名字。
